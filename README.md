🧮 Calculadora Base 21 — Sistema “Mamma Mia”

📌 Sobre o projeto

Este projeto consiste em uma calculadora interativa que utiliza um sistema numérico alternativo baseado no alfabeto italiano, denominado Sistema Mamma Mia (Base 21).

O projeto foi desenvolvido como trabalho acadêmico em grupo, com o objetivo de explorar conceitos de lógica de programação, sistemas numéricos e desenvolvimento de interfaces interativas.

Diferente dos sistemas tradicionais (decimal, binário, hexadecimal), este sistema utiliza 21 caracteres alfabéticos como representação numérica, criando uma abordagem simbólica e criativa para manipulação de valores.


---

🔢 Como funciona o sistema

O sistema utiliza o seguinte conjunto de caracteres:

A B C D E F G H I L M N O P Q R S T U V Z

Cada letra representa um valor numérico:

Letra	Valor

A	0
B	1
C	2
...	...
Z	20


👉 Isso define uma base 21

🧠 Lógica de conversão

📌 Base 21 → Decimal

resultado = resultado * 21 + valor_do_caractere


---

📌 Decimal → Base 21

resto = numero % 21


---

📌 Representação Binária

Cada símbolo é representado em 5 bits:

2⁵ = 32 possibilidades

Sistema utiliza 21


Exemplo:

M → 10 → 01010  
I → 8  → 01000  
A → 0  → 00000
